6. The Blind-Spot Theorem (Theorem 2)

Fundamental Limits
  • Visibility Condition: A hardware noise channel \(\mathcal{E} = \sum_k E_k \rho E_k^\dagger\) is visible to sentinel \(\Pi\) if and only if at least one Kraus operator anticommutes with \(\Pi\):
$$\exists k: \{E_k, \Pi\} = 0 \implies \Delta \nu_t = \frac{1}{2}\mathrm{Tr}\left(\Pi \mathcal{E}(\rho) - \Pi \rho\right) > 0$$
  • Commuting Blind Spot: If all Kraus operators commute with \(\Pi\) (\([E_k, \Pi] = 0\)), the symmetry syndrome remains strictly invariant (\(\Delta \nu_t \equiv 0\)), even while the learning task risk degrades (\(\Delta R_t > 0\))!
  • Exact Closed-Form Laws:
    • \(\mathbb{Z}_2\) Parity: \(\nu_t = \frac{1}{2}[1 - (1-2p_t)^d (1-2r_t)^n]\)
    • \(U(1)\) Charge-Walk: \(\nu_t = 1 - [z^0] P_d(z)\) via Laurent generating polynomials
